# 3D CD Model

Bu dizine `cd_case.glb` adında bir 3D CD jewel case modeli yerleştirin.

## Önerilen Model Kaynakları:
- Sketchfab: https://skfb.ly/pNoPz (CC Attribution lisanslı)
- Sketchfab'dan GLB/GLTF formatında indirin
- Dosyayı `cd_case.glb` olarak bu dizine kaydedin

## Model Gereksinimleri:
- Format: GLB veya GLTF
- Kapak yüzeyi düz (texture mapping için uygun)
- Ölçek: Uygulama otomatik ölçeklendirme yapar

## Not:
Eğer model dosyası bulunamazsa, uygulama otomatik olarak procedural (kod ile oluşturulmuş) 
bir CD jewel case modeli gösterecektir.
